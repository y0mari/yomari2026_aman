# Tyre Model Simulation

This repository contains a Magic Formula tyre force simulation in Python. It computes tyre lateral (side) and longitudinal (brake) forces versus slip using empirical coefficients.

## 📋 Files

- **s2510787037.py** – Main script to run the simulation  
- **tyre_model.py** – Tyre force computation model  
- **plotter.py** – Force plot generator  
- **constant.py** – Tyre force coefficient constants  
- **requirements.txt** – Python dependencies
